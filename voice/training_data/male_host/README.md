# Male host training audio

Drop the **male anchor** voice training clips here as `.mp3` (or `.wav`,
`.m4a`, `.flac`, `.ogg`) files. Filenames don't matter — the cloner discovers
them with `glob`. Aim for ~2 minutes total of clean, single-speaker audio
split across one or more files.

Then run:

```bash
python main.py --setup
```
